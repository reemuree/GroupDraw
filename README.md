# 🎲 GroupDraw — Presentation Group Lottery

**GroupDraw** is a simple web-based lottery application designed to make student selection and presentation topic distribution fair, random, and easy.

## ✨ Features

- 🎓 Student management with names and roll numbers
- 🎯 Random student selection for presentations
- 📝 Custom presentation topics and questions
- 👥 Flexible student grouping
- 📊 Lottery results and session history
- 💾 Browser LocalStorage for saving data
- 📤 JSON backup and restore
- 🌐 Simple web-based interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- JSON

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Add student information and presentation topics.
5. Start the lottery and view the results.

No backend server is required for basic use.

## 💾 Data Storage

GroupDraw stores application data in your browser's LocalStorage.

- Data is saved locally on your device.
- Clearing browser site data may erase saved information.
- Export JSON backups regularly.
- Data is not automatically synchronized between devices.
